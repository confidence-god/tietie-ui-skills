# UI Theme

把项目用途与审美偏好转化为用户能看见、能确认、可供后续页面生图复用的主题。默认中文交流与标注，必要时附英文视觉关键词。

## 边界与状态

- 仅负责主题奠定。正式页面生图、素材提取、前端复刻及动效实现留给后续阶段，不自动启动。
- 项目功能、目标用户与使用场景必须明确；完整 MVP 不是前置条件。已有 MVP 时只提取影响主题的事实，不要求补齐业务规格。
- 参考图、吉祥物均可选。主题可通过字体、材质、构图或图形建立识别度。
- 不生成 HTML、CSS、框架配置、响应式断点或完整组件系统。不依赖其他主题奠定技能。
- 区分访谈中、待生图、待用户确认、已锁定。工具阻塞时记录原因；文字方向被认可不等于图片获批。

## 1. 项目访谈

读取 [访谈指南](references/interview.md)。复用已有信息，每轮至多问三个最影响方向的问题，等待回答后继续，不一次发出完整问卷。

了解项目做什么、为谁服务、主要使用场景与期望感受。确认是否有参考图、现成视觉资产或吉祥物意愿，已有答案时跳过。实际查看参考图并问清借鉴与排除的维度，不能默认整套继承。

用户没有方向时，根据项目作用与氛围提出二至三个真正不同的方向，分别描述视觉表现、适配原因和取舍，推荐一个并询问关键偏好。用通俗效果描述引导，不要求用户先懂设计术语，不擅自批量出图。

将信息区分为项目事实、用户偏好、助手建议和待确认项。完成标准：功能、用户、主要场景与期望氛围明确，足以判断主题适配性。

## 2. 收敛主题

将抽象形容词落实为画风、造型、材质、光影、色彩关系、字体气质、疏密、视觉词汇与禁区。互斥方向先追问，不无差别混搭。

满足以下条件即可出图，不追求穷尽设计参数：
- 项目服务谁、传达什么感受已明确。
- 一个主要画风与质感方向已选定，或用户授权按推荐方向尝试。
- 色彩倾向、字体气质、保留项和禁区有依据；次要缺口可作为明确标注的建议。
- 可选参考图的用途及是否加入吉祥物已明确；缺少参考图不阻塞。
- 没有尚待用户决定、会改变整体方向的矛盾。

出图前简短回述方向与建议性假设。已有充分授权时直接生图，不增加逐项审批；重大分歧仍须等待回答。主题保持草案状态。

## 3. 真实生图

读取 [设计板与交接规范](references/board-and-handoff.md)。检查当前会话可用的生图技能，优先使用 Codex 当前可用的生图能力；完整阅读所选技能及其要求的说明后调用。用户明确指定渠道时尊重其选择。

检查底层工具、必要输入、权限与凭据是否可用。技能存在不代表能实际生图。没有可用渠道，或存在无法解决的权限、额度、凭据或调用问题时，说明阻塞并询问用户是否有其他生图渠道。可保留草案与提示词，但不能声称图片已生成或主题已锁定。不得自行将私人参考图公开托管。

默认每轮生成一张以视觉主题为主体的统一设计板，包含核心视觉场景或符号、主色调、设计语言、质感氛围、视觉词汇和视觉边界。可加入一个小型、低信息量的界面片段，证明主题能够落到产品界面；它不是必需项，也不得成为整张图的主视觉。避免完整手机样机、完整首页、完整导航、复杂工具栏、列表或可识别的产品信息架构，不在此确定正式页面结构与交互。

必须真实调用图像生成能力。不用 HTML 截图、SVG、代码绘图或纯文字替代确认图，不批量制作生产素材。

完成标准：取得可展示的真实生成图，记录版本、图片位置和实际提示词。

## 4. 视觉核验与确认

实际查看图片，按参考规范检查完整性、一致性、项目关联与中文可读性。工具调用成功不等于视觉核验通过。额外检查界面片段是否只是风格证据，是否错误建立了完整产品布局或强制性的页面结构。不能查看图片时如实说明，不声称视觉已验证。

修正明显缺漏、乱码或方向冲突后提交确认；持续失败时说明问题并询问处理，不无限重试。精确字体、色值遵循参考规范中的真实性规则。

在对话中展示完整设计板，标明版本、核心方向、仍属建议的细节或限制，明确询问用户是否认可这一版作为后续页面生图依据。只有文字或文件路径不算展示图片。

按反馈修改受影响的维度，保留已认可部分；重大改向重新收敛。每次修订产生新版本，不覆盖已批准图，不将新图自动视为获批。

完成标准：用户明确认可一张具体版本，且无未处理的修改要求。生成成功、局部满意、要求再改或含糊的“继续”均不自动构成锁定；有歧义就简短核实。

## 5. 锁定与交接

确认后按参考规范交付三类成果：确认版设计板图片、简短主题说明、可复用生图提示词。提示词必须明确区分固定视觉约束与可变页面结构，禁止把设计板中的界面片段当作页面模板。保存到当前项目或用户指定的输出目录，不写入技能安装目录。

记录批准版本和确认依据；区分固定视觉约束与可随页面变化的功能、文案、数据和布局。新的主题变更保持待确认，原批准版本继续有效，直到替代版获批。

完成标准：三项成果可访问并指向同一批准版本；提示词能指导后续页面生图而不复制设计板分区或迷你样张布局。说明交付位置后停止，不自动进入下一阶段。
