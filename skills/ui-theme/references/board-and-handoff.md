# 设计板与交接规范

## 设计板内容

默认一张清晰、便于整体审阅的设计板。选用渠道支持的画幅，优先给视觉方向与质感足够面积，不机械等分格。中文标签简短，必要时附英文关键词；整板与样张使用统一美术语言。

| 内容 | 可见证据 |
| --- | --- |
| 视觉方向 | 一个核心视觉场景、符号或主题化构图；如需证明界面落地，可加入一个小型、低信息量的界面片段。界面片段不应成为主视觉，不得形成完整首页、设备样机、导航、工具栏、列表或明确的信息架构。可选吉祥物融入场景。 |
| 主色调 | 主色、辅色、背景与强调色，标明用途及大致面积关系；样张实际体现搭配。 |
| 设计语言 | 标题与正文样张、字体气质、轮廓、合适的图标或插画处理。 |
| 质感氛围 | 样张中真实体现材质、光影、纹理和层次，必要时加细节放大，不只写材质标签。 |
| 视觉词汇 | 少量可复用形状、纹样、物件、线条或装饰手法，配短名称。 |
| 视觉边界 | 三至五条项目相关限制，如纹理位置、装饰强度、禁用造型。简短标注，反例不占据整板。 |

按钮、卡片或局部控件按项目选择，只作风格样例，不强制全部出现。默认优先展示视觉主题，而不是完整产品界面；不将任何界面片段视为正式业务布局。

## 生图提示词

将以下信息填写成当前项目的具体内容再调用：
1. 任务：单张主题设计板、中文说明、服务后续页面生图。
2. 项目：用途、用户、主要场景与期望情绪。
3. 主导视觉：媒介、造型、材质、纹理、光照、空间和疏密。
4. 色彩：角色、配色关系和大致占比。
5. 字体：标题与正文气质、产品语言、短样张文字。
6. 视觉词汇、可选角色、参考图用途与需保留的特征。
7. 六类内容的表现与主次，不限定统一排版。
8. 用户禁区及需避免的视觉漂移。

通过渠道真正支持的方式传入参考图；提示词提到文件名不代表模型看到了图片。记录输入图片及用途。

## 核验与真实性

实际检查六类内容是否可辨认、主样张是否关联项目、样张与色卡是否一致、材质光影是否呈现、中文是否可读、有无拥挤遮挡、是否擅加吉祥物或禁用效果。若出现界面片段，检查它是否保持低信息量，是否只是视觉证据，是否错误暗示了固定页面结构、设备形态或产品类型。

生图字体只证明气质，不证明用了某个真实字体文件。可列具体字体候选，但未验证字形、可用性或授权时必须标注未验证，不承诺精确还原。

色卡只证明搭配，不证明像素等于标注色号。精确色值可在主题说明中作为目标建议值记录，须与图核对，不假称已测量。明显冲突时修图或向用户说明并取得确认，不悄悄替换。

关键乱码优先缩短标签或重新生成。非关键文字缺陷明确说明并在文字文件中提供准确内容，不声称图中已正确呈现。无真实图像时不输出已确认状态。

## 反馈

展示版本后询问是否认可作为后续页面生图依据。记录反馈影响的维度，仅修改这些维度及必要关联部分，解释关联变化。局部认可不等于整板批准。修订后重新展示并等待批准。

## 三项交付

保存到项目主题输出目录，以下为建议文件名。三项必须指向同一批准版本。

### 确认版图片

保存 `theme-board-vNN.png` 或真实格式，保留高质量原图及版本，不覆盖历史批准图片。只有链接时说明有效期等限制，条件允许时按工具规则保存本地副本。

### 简短主题说明

保存 `theme-brief.md`，包含：
- 项目用途、用户与氛围。
- 状态、批准版本、图片位置和用户确认依据。
- 锁定的画风、材质、光影、色彩角色、字体气质、视觉词汇与边界。
- 可选角色或参考图的保留特征。
- 未验证的字体、色值或实现可用性，区分视觉批准与工程验证。
- 可变项：页面功能、文案、数据、布局和局部构图。

保持简短，不附完整访谈记录或完整 MVP。

### 可复用生图提示词

保存 `theme-prompt.md`，包含两个部分：

**页面生图主提示词**：写入批准的具体主题，以“生成实际产品页面设计图”为目标。区分固定视觉约束、可变页面输入和参考图用法。可变项使用 `{页面功能与内容}`、`{目标画幅}` 等明确字段；固定主题不可留成空白占位符。只有用户批准内容才能称为锁定。

要求下一阶段结合页面 MVP 填充内容并重新解决布局。继承设计板画风、质感、配色、字体气质和视觉词汇，不复制色卡、标注、设计板分区、设备样机、界面片段或其迷你页面布局到实际页面。明确说明界面片段仅用于表达风格，不是页面模板；后续页面必须根据当前页面功能、用户任务和目标画幅重新组织信息架构与布局。

**设计板复现记录**：保留批准版本实际使用的提示词、渠道名称、参考图用途和可取得的生成标识。不可取得的种子等信息省略，不承诺跨调用或跨模型逐像素复现。

交付时展示确认版图片并链接两份文字成果，然后结束主题阶段。
