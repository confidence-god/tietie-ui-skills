# 自适应主题访谈

## 提问策略

先了解项目，再问对整体效果影响最大的风格问题，最后补局部偏好。每轮至多三个问题，已有信息直接引用。以下为内部判断维度，不是要用户一次填完的问卷。

| 维度 | 收集内容 | 通俗问法示例 |
| --- | --- | --- |
| 项目 | 核心用途、目标用户、高频行为、使用环境 | 用户打开它最常做什么？ |
| 氛围 | 期望感受与不希望产生的感受 | 希望它带来什么感受？什么氛围不适合？ |
| 画风 | 摄影、二维、三维或混合；写实度、线条和造型 | 喜欢手绘痕迹，还是整洁精确的造型？ |
| 质感 | 材质、粗糙度、纹理强度、光影、空间 | 材质接近什么物体？表面光滑还是能看见纹理？ |
| 色彩 | 冷暖、明暗、饱和度、主辅关系、品牌限制 | 有哪些想保留或避开的颜色？ |
| 字体 | 产品语言、标题个性与正文阅读需求 | 标题希望有什么性格？正文有长时间阅读需求吗？ |
| 构图 | 疏密、留白、层次、装饰强度、设备形态 | 界面更紧凑还是舒展？主要用于手机还是桌面？ |
| 视觉词汇 | 重复使用的形状、纹样、物件与处理手法 | 有没有希望反复出现、让人记住的图形？ |
| 边界 | 禁用效果、可接受混合程度 | 哪些效果即使好看，也不适合这个项目？ |

按项目取舍深度，不把每个维度变成必答题，不询问技术栈、CSS 参数或动效实现方案。

## 没有方向

先用项目事实推导视觉需要，再提供二至三个可比较的方向。每个方向包含通俗名称、具体画面描述、与项目用途的关联和一项取舍。避免只给“现代、简约、高级”等空泛标签。

推荐其中一个，问能区分方向的关键问题。用户仍难判断时，用熟悉的物体或环境解释材质与光照。用户授权直接尝试时记录假设，生成一版草案供判断，不无限追问。

例如对长期记录工具，问“希望界面本身有手作纹理，还是只在插画里体现？”比问“喜欢什么风格？”更具体。此例仅示范问题形式，不是默认主题。

## 参考图与吉祥物

实际查看参考图，区分观察和推断。问清继承与排除的部分，不连同原图行业、文案和布局一起照搬。多图分别记录用途，例如配色参考与材质参考；冲突时确认主导方向。无法访问时请求重新上传或描述。

吉祥物意愿只问一次。已有角色时确认不可变的轮廓、比例、颜色与关键特征，使用渠道支持的参考输入。未见视角不当作已知设定。需要新角色时仅探索主题示意，不扩展到全套设定、表情或动画资产。不需要角色时以字体、材质、图形或构图建立识别度。

## 回述

出图前短述项目定位、画风、材质光影、色彩关系、字体气质、视觉词汇和禁区，单列少量建议性假设。主要方向冲突须先解决；无需所有次要参数都有用户逐项批准。
